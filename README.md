# 姨妈们官网

“姨妈们”是一个面向家庭成员的经期记录与预测微信小程序。用户可以在同一个月历中管理多位成员的经期记录，查看周期预测，并通过邀请与家人共同查看和编辑记录。

## 项目简介

本仓库是“姨妈们”官网的静态网站项目，页面使用 HTML、CSS 和原生 JavaScript 构建，适合直接由 Nginx 或其他静态文件服务器托管。

官网内容以文本为主，便于搜索引擎收录，并提供小程序码、产品特色、家庭分享说明、隐私说明和意见反馈入口。

## 主要功能介绍

- 多成员经期记录：在同一个月历中查看不同成员的记录。
- 周期预测：根据历史记录、经期时长和周期长度生成预测结果。
- 家庭分享：通过邀请让家人共同查看和编辑成员记录。
- 历史记录管理：支持查看、修改和删除经期记录。
- 提醒设置：为成员设置预测经期提醒。
- 意见反馈：用户可提交建议，后台审核后可以在官网公开展示。

页面中的月历和手机界面属于产品功能示意，具体数据以微信小程序实际显示为准。预测结果仅供日常参考，不作为医疗诊断、避孕或其他医疗决策依据。

## 本地预览

项目无生产环境 Node.js 依赖，可以直接使用 Python 启动静态服务器：

```bash
python -m http.server 8080
```

然后打开 <http://localhost:8080/>。

## 部署说明

生产环境可将仓库中的静态文件部署到 Nginx 网站目录。当前线上部署目录为：

```text
/var/www/aunts-web
```

官网使用 HTTPS。现有 Nginx 配置中，官网负责静态页面和资源；`/api/`、`/admin/` 等路径由后端服务继续处理。

部署时只需要发布公开网站文件，不要把服务器密码、SSH 私钥、微信 AppSecret、数据库密码、访问令牌或其他敏感配置提交到仓库。敏感配置应保存在服务器环境变量或独立的服务器配置文件中。
